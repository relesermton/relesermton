### 🔐 Flagship: [virtual-tpm](https://github.com/relesermton/virtual-tpm)

A **`tpm.msc`-style management console + virtual TPM**, built from scratch:

- **Pure Python** — `tkinter` MMC-lookalike UI, `hashlib` PCR engine, `pathlib` state files.
  No TPM hardware, no wire protocol, stdlib only.
- **Windows kernel driver scaffold** compiled with **MinGW-W64** — no Visual Studio, no WDK —
  SHA-256 test-signed and proven loadable (Phase 1 ✅).
